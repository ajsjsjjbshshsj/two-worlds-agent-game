## 已知问题与限制

- 本机 Windows 环境：`test_command_restart` 与 `test_websocket` 回环夹具子进程连接超时、`tests/ai` 超长参数用例触发 Windows 环境变量 32767 上限；已在未改动基线复现确认非回归，CI ubuntu 覆盖。双浏览器 e2e 的子进程+WS 在同机可用。
- 备份/恢复 bash 包装脚本仅支持 Linux（flock/stat/realpath）；Windows 本地需用官方 Database Tools 等价流程（tests/t16_backup_restore.py）。
- 限频为固定窗口共享计数器：窗口边界允许短时双倍突发；未做滑动窗口/令牌桶。
- WS 快照轮询约 250ms：高频操作合并为最新快照，中间版本不逐帧推送（设计取舍，非缺陷）。
- 待确认命令 IndexedDB 记录每来源 32 条/24 小时；NPC 私聊与分享正文仅页内内存，刷新后不可自动确认（设计取舍）。
- 单机 standalone Mongo 为当前生产假设；无副本集即无自动故障转移。
- 前端 PWA 仅预缓存公开外壳；离线不能进行任何需服务端确认的操作（设计取舍）。

## 可能影响正式上线的风险

1. **真机兼容性未知**：iOS WebKit 的 Cookie/WS/PWA 行为差异可能导致移动端无法登录或断线恢复失败。上线前必须真机验收。
2. **邮件可达性**：未验证真实 SMTP 送达率与退信处理；注册/找回依赖邮件，服务商故障即阻断新用户。
3. **素材与许可**：正式美术/音频缺失与许可未核验，当前内容不可对外发布。
4. **单点存储**：standalone Mongo 无高可用；备份恢复已验证但 RPO/RTO 未承诺。
5. **进程内投递队列**：服务重启会丢失在途验证码邮件（用户可重发，体验损失而非数据损失）；生产建议持久 outbox。
6. **安全绝对保证不存在**：限频/CSRF/隔离已按契约验证，但渗透测试与第三方审计未执行。
