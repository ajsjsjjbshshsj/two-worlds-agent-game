# TwoWorlds · 玩家操作指南

你和搭档会扮演不同的角色。每个人都能看到一些只有自己知道的线索，也能做对方做不到的事。可以用你们平常的通话方式交流，坐在一起也可以直接说。只需交流游戏里的事情。

## 打开游戏和登录

1. 打开组织者提供的测试入口。每人使用自己的浏览器窗口和测试账号。若共用一台电脑，请让组织者准备两套独立的浏览器用户配置。
2. 输入分给你的测试邮箱和密码，点「登录」。如果需要亲自注册，点「立即注册」，填写试玩昵称和专用测试邮箱，点「发送验证码」。主持人会单独告诉你验证码。填入验证码和专用密码，再输入一遍密码确认，点「注册并登录」。
3. 登录后进入「我的房间」。如果先打开了搭档发的邀请，登录后也可以在这里找到加入提示。

## 两人进入同一故事

1. 其中一人点「创建新房间」，成为角色 A。房间会显示邀请链接。点「复制邀请链接」，只发给搭档。无法自动复制时，可手动复制页面显示的完整链接。如果房间页面没显示链接，点「生成新的邀请」。
2. 搭档在自己的浏览器打开完整链接，以自己的账号登录后，点「确认以当前身份加入 · 角色 B」。若提示邀请失效，请 A 生成新邀请。生成新链接后请使用最新的一条。
3. A 可以点「刷新成员状态」，直到看到「双方已就位」。两人都点「进入剧本书架」，找到主持人指定的故事。先进入的人点「开始这段故事」，另一人如已在书架上可点「刷新书架」，再点「继续原存档」。确认两人进入了同一个故事。

## 看线索、做选择和暂停

- 从场景、「我的设备」「当前观察」「我的私人线索」开始。可以把你注意到的变化讲给搭档听。若出现「分享已发现线索」，也可把选中的游戏线索放到双方都能看的「已公开线索」。
- 在「我能做什么」选择一项行动，按界面要求填写并点「确认」。留意进度与提示；一次按下后先等确认。遇到离线、操作结果待确认或看不到更新，等网络恢复，按页面提示读取进度或核对原操作，也可以请主持人协助。
- 接近结尾时，与搭档讨论各自的选择，再按页面提示提交。当页面显示「已完成」，可以查看共同回顾。
- 每次确认成功的行动会自动保存。暂停前等当前行动确认，再点「返回书架」或关闭游戏；在同一测试环境仍开放时，用原账号回到同一房间，在同一剧本点「继续原存档」。已结束时可点「查看完成存档」。共用设备离开时，从「我的账号」点「登出」。本次测试环境收场后，临时存档会被清理。
