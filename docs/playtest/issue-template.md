# TwoWorlds · 试玩问题处理与记录模板

| 级别 | 判断 | 处理 |
| --- | --- | --- |
| P0 | 严重安全或隐私风险，例如串档、未经同意的外传或显示搭档未公开的信息 | 立即停止相关场次及待开始场次，保护现场与账号，联系组织者隔离实例。仅用合成身份复现，记录最少脱敏事实；由负责人员确认修复及隔离复验后，另行批准开测 |
| P1 | 登录、加入、存档或游戏进度被阻断且无法安全继续 | 优先排查与修复，记录受影响范围与临时处理；核心路径复验后再开对应场次 |
| P2 | 能继续，但明显影响体验，例如目标不清、角色长期等待或设备交互困难 | 进入下一轮体验优化，按影响人数和复现情况排序 |
| P3 | 普通建议或视觉优化 | 纳入产品需求池，记录期望和使用情境 |

主持人先登记现象、风险和场次编号。负责人复核级别，以合成测试账号复现并补充「复现」「不稳定」「未复现」或「待查」。重复反馈保留各自的匿名计数，并关联同一问题编号。状态依次可用 待核实 / 已分级 / 处理中 / 待复验 / 已关闭。只有复验确认或明确记录无法复现及关闭理由后才结案。
