# TwoWorlds · 试玩隐私与同意

## 参与者须知

两人分别确认年满 18 岁、自愿参加，且明白主持人会用编号记录设备类型、入场与游戏行为的次数和时间、技术问题及问卷反馈。主持人可在同意范围内观察操作和游戏协作，只记行为和次数。每个人都可以跳过问题、暂停或退出，并通过组织者提供的联系渠道用自己的试玩编号申请删除仍可定位的记录。退出无惩罚。

默认不录音、不录像、不截屏、不转写。未来如需录制，要先单独说明用途、范围、谁能访问、保留期限和如何撤回，并取得两人明确同意。不参加录制也可参加不录制的场次。试玩无支付环节。

请使用主办方安排的测试身份。试玩中不需要提供真实姓名、私人聊天记录、亲密关系信息或个人邮箱。游戏使用本地固定的 Demo 示例回复，当前网页未开放 NPC 对话入口；不把试玩信息发给真实 AI Provider。参与者使用的外部通话工具由其自行选择，请关闭该工具的自动录制和转写。

## 主持人的数据处理

1. 对外联系与时间安排由组织者保管，和观察表、同意表及问题台账分开。报告只用 Couple-01 等编号与 A/B。少见的设备组合或自由题内容若可能识别参加者，只作分类概括。
2. 使用独立测试实例及数据库。每对两个独立测试账号与新房间，验证码经独立控制台以最小范围转达，专用密码只交本人。账号、密码、验证码、密钥、Cookie、邀请链接、原始日志及任何私人对话不得写入观察表、问卷、问题单、截图或 Git。演示模式使用本地处理，无真实邮箱投递、付费 Provider 或外部追踪。
3. 受控记录仅组织者与授权主持人或分析人员可访问。默认不复制原始应用日志或导出完整库；运行临时库、凭据和控制台日志场次收尾即清理。若约了新时段，重新开测试实例和测试账号。测试名单和凭据存放位置不与观察数据共享。
4. 同意表、带编号观察、问卷及可定位的问题笔记自该场次结束起最多保留 **30 天**。组织者在收场时登记到期日并检查删除，清理误同步的副本、下载与回收站；如存在批准的备份，按同一到期日移除对应记录或销毁独立备份。仅保存无法再关联个别参与者的汇总及脱敏问题。
5. 收到退出或删除请求时，立即停止采集，由组织者按编号核对受请求者，尽快从仍可定位的文件、问卷、台账及相关副本移除该人的数据。需要共同归属的记录，删掉可定位的内容并标记指标缺失。删去联络对应表中相关项，向参与者确认处理范围；已无法关联到个人的汇总不承诺逆向定位。若尚未汇总，按实际可用数据重算，保持分母透明。
