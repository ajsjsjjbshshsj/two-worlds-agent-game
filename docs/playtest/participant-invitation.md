# TwoWorlds · 双人试玩邀请准备稿

TwoWorlds 是一款两个人一起玩的剧情谜题游戏。你和伴侣会从不同的角色出发，各自看到一些线索和变化。你们可以边聊边尝试，看看能不能一起走到故事的结局。

我们准备找 3～5 对情侣体验早期版本。你们都需要年满 18 岁，且分别愿意参加。会使用电脑或手机即可，平时不玩游戏也可以。游戏仍在原型阶段，部分画面和声音是占位素材。当前版本使用固定的演示回复，不接入在线大模型；试玩网页暂时没有可用的 NPC 对话或内置通话入口。

## 参加前

- 请为一套剧本预留约 75–90 分钟，包含登录入场、约 50–70 分钟的游戏体验和简短反馈。第二套剧本另行安排完整场次，不要求同一天连续完成。
- 建议每人一台能上网的电脑，使用 Chrome 或 Edge。想用手机时，请提前告诉组织者，让我们先确认你的设备能进入。异地可用你们平常的通话方式，现场也可以直接交流。
- 游戏需要登录。组织者会发给你个人的测试账号。需要亲自体验注册时，也会提供专用的测试邮箱名和验证码；请别用自己的邮箱或常用密码。组织者将单独告知测试入口与时间。

## 会记录什么

如果你同意，主持人会用编号记下设备类型、是否顺利入场、游戏用时、卡住或求助的次数，以及你自愿提供的反馈。试玩后两个人各自填一份问卷，欢迎说出没意思、困惑或想退出的原因。感受不同也没关系。

试玩过程默认不录音、不录像，也不要求提供私人聊天记录、真实姓名或感情经历。以后如需录制，会另行征求你们的明确同意。你可以跳过问题、随时暂停或退出，也可以要求删掉还能按编号找到的记录。试玩没有购买环节，不会产生未经你同意的费用。[隐私与同意](privacy-and-consent.md)
